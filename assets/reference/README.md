## 01 风格锚点：为什么它最重要

它是**唯一一张必须每次都用**的图。作用不是「给个风格方向」，而是把画风钉死：

- 线条粗细、笔触松紧
- 只用纯黑填色（眉、须、眼珠、头发、冠帽），没有灰阶
- 头大身小的夸张比例
- 白底、无阴影、无排线、无纸纹

不用它，图生图会漂；用了它，角色可以整批换，画风不动。
这正是「每条视频角色都不同」需要的性质。

**用法：**

```
参考图: assets/reference/01-style-anchor.png
相似度: low（ImageGen 是 input_fidelity，MJ 是 --iw 0.3，SD 是 IP-Adapter 0.35）
```

⚠️ 相似度千万**不要调高**。高了模型会照抄这张图的姿势（举手比 V），
无视你写的动作。这是整个流程里最容易搞错的一个参数。

## 02 对话格：要抄的是「关系」，不是画风

看得四件事：

1. **角色之间有动作关系** —— 左边的抢、中间的挡、右边的喊，不是并排站。
2. **气泡是椭圆、橙色、尾巴指向说话的人**，三句话三个气泡，不等大。
3. **红圈只压一处** —— 在全场最安静的那个东西上。
4. **底色浅蓝**，不是白。

自己出图时，模型只画角色（**绝对不让它画气泡**），气泡由
`lib/comic_layer.py` 的 `bubble()` 叠上去。

---

## 03 信息图格：要抄的是「层级」

看得四件事：

1. **一眼看完** —— 三到四行，每行一个大信息。
2. **两级层级** —— 大字（狠话）+ 小字（解释），没有第三级。
3. **强调色只在一处** —— 红只用来标「结论 / 对比」。
4. **每格配一张小插图** —— 但插图是配角，文字才是主体。

底色米黄。竖排时间轴比横排好用，因为手机是竖的。

## 04 / 05 生成底图：用来校准「够不够进引擎」

这两张是真实产出，可以直接跑：

```bash
python lib/lineart_clean.py assets/reference/05-gen-character-raw.png --stats
```

`largest_share` 会给你 90%+ —— 单人图必然如此（人物本身就连成一块），
所以**别拿这个数判单人图**。它只看多人格：>90% 说明几个主体连成一片了，
判读和处置见 `scripts/pipeline.py` 关卡②。

判断一张生成图**能不能用**，只有两条（其余都是「能出片，只是不完美」）：

- 有东西画出来了（不是几乎空白，不是整片纯黑）
- 该在的人都在，没有凭空多出来的人

**背景是浅灰、有灰阶、上方留白少、角落写了字 —— 都不影响出片。**
二值化会吃掉灰阶，气泡往上挪能解决留白，角落的字在手机上更看不见。
`pipeline.py --stage image` 只会拦「缺图 / 几乎空白 / 整片涂黑」，
其余只记录 —— 不要自己加判定。

## 06 分镜总览：用来校准节奏

七格，68 秒。看节奏：

| 格 | 类型 | 时长 | 作用 |
|---|---|---|---|
| 1 | 对话 | 9.8s | 冲突先行，不铺垫 |
| 2 | 信息图 | 8.5s | 底牌（兵力对比） |
| 3 | 对话 | 13.4s | 第一回合 |
| 4 | 对话 | 8.2s | 第二回合 |
| 5 | 信息图 | 6.2s | 战况汇总 |
| 6 | 对话 | 12.1s | 主角反击 |
| 7 | 对话 | 10.5s | 收尾加码 |

**对话格 8–13 秒，信息图格 6–9 秒。** 每个对话格里，画面在 6–9 秒画完，
剩下的时间留给气泡弹出和观众反应。

如果一格超过 15 秒，说明旁白太啰嗦，砍字而不是加画面。
但砍的是废话（「因此」「由此可见」、重复解释），不是人物说的话 ——
台词要留在念白里。**砍到每格只剩一句「他说了一句」，就是砍错了地方。**

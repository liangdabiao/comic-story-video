## 1. 结构：三段，一段都不能省

```
┌─ 风格前缀（逐字照抄，永不改动）────────────────────┐
│ 白底黑白线稿的简笔漫画，手绘马克笔风格。纯白背景，  │
│ 只有黑色线条和少量纯黑填色（眉毛、胡须、眼珠、      │
│ 头发、冠帽），绝对不要灰度、不要阴影、不要排线、    │
│ 不要纸张纹理、不要彩色。线条干净肯定、带轻微不规则  │
│ 的手绘感。漫画夸张比例，头大身小。                  │
└────────────────────────────────────────────────────┘
┌─ 内容（每次改这段）────────────────────────────────┐
│ 内容：<谁> + <什么表情> + <什么动作，朝哪> + <在哪>  │
└────────────────────────────────────────────────────┘
┌─ 尾部约束（逐字照抄）──────────────────────────────┐
│ 画面上方留出大片纯空白（留给对话气泡）。            │
│ 绝对不要画任何文字、气泡、标题、对话框、边框、水印。│
└────────────────────────────────────────────────────┘
```

**为什么风格前缀要这么长**：它不是描述，是**排除清单**。
生成模型默认会加阴影、加灰阶、加纸纹 —— 每一样都会让引擎把噪点当笔画描。

## 2. 六类内容模板

### 2.0 先开「角色身份证」，再写多角色格

多角色格最常见、也最致命的失败不是动作画错，是**两个人长得像同一个人**。
观众会把配角认成主角，整段叙事直接崩（实测：晏子被画得跟门卫同款方冠 + 同款大胡子，
读出来就是「两个楚王」，而且画面本身毫无异常，不抽帧根本发现不了）。

所以写 prompt 之前，先给每个角色定四个字段，**任意两人至少三项不同**：

| 角色 | 头饰（最容易撞） | 胡须 | 衣服 | 体型 |
|---|---|---|---|---|
| 主角·晏子 | **深色软布巾小髻，无冠** | **无须** | 宽袖长袍、双手拢袖 | 矮（只到旁人胸口） |
| 对手·楚王 | 高耸硬方冠、顶上一块横板 | 满脸络腮浓须 | 宽袍大袖、腰束大带 | 胖、坐姿 |
| 门卫 | 高竖条纹硬方冠 | 满脸络腮浓须 | 短打束腰、长靴 | 高壮 |
| 士兵 | 带缨头盔 | 短须 | 鳞甲、绑腿 | 壮 |

两条硬规则：

1. **主角的头饰要跟所有配角不同类。** 布巾 / 无冠 / 儒巾留给主角；方冠、冕冠、
   头盔留给对手和兵。让主角戴一顶「矮一点的同款方冠」是无效区分——模型只会画出
   同款方冠，观众看到的就是同一个人。
2. **主角跨格必须同一个组合。** 每格都写一遍完整四字段，别写「还是那个人」。

写法上还要做一次**收尾复述**，因为模型对「复制粘贴两个人」很敏感，写一遍不够：

> 两个人必须一眼能分清：矮的那个人头顶是软布巾、没有胡子、圆脸；
> 高的那个人头顶是高方冠、满脸大胡子、方脸。**帽子样式和胡须绝对不能一样。**

### 2.1 单人表情特写（反击、爆发用）

> 一个戴纶巾的中国古代文士单人半身特写，头部占画面主要面积。他脸正对观者，
> 眉毛倒竖拧成两块，眼睛瞪得很大，嘴角向下压，一脸怒火。双手自然收在胸前，
> 一只手握着收拢的羽毛扇。不要画举起手臂的动作，不要画手指比 V 字，双手不要高过肩膀。

关键：**必须给「不要举手」这类负向约束**。参考图里的人是举手比 V 的，
不写这句，几乎必抄。

### 2.2 多角色对话格（2–4 人，最常用）

> 画面右侧站着一个戴纶巾的瘦小文士，抱着羽毛扇，站得笔直，眼皮半垂。
> 画面左侧并排站着三个戴冠的文官，三个人都伸出右手臂，手臂水平指向右侧那个文士，
> 嘴巴张开在说话，表情激动。三个人的手臂都指向同一个人。人物高度相近、身体完整。

关键：
- **每个人都要写「在画面哪一侧」**，不写就会挤成一团。
- **同一个动作要重复两遍**（「都伸出右手臂，手臂水平指向右侧」+「手臂都指向同一个人」）。
- 人数 ≥3 时，说清「谁指谁」，否则会互相指。

### 2.3 两人对峙（冲突最高点）

> 两个人物横向对峙。画面左侧一个壮年文官身体大幅前倾、双手向前伸、表情咄咄逼人；
> 画面右侧一个戴纶巾的瘦小文士侧身站着，一手摇着羽毛扇，眼皮半垂，完全不为所动。
> 两人高度相近、身体完整。画面上方留大片纯空白。

关键：一攻一守，**要有身体朝向的对比**（前倾 vs 侧身、逼视 vs 半垂眼）。

### 2.4 群体围观（被围攻、被质疑）

> 画面中央一个戴纶巾的瘦小文士抱着羽扇站得笔直、神情淡定；
> 周围一圈四个文官把他围住，各自伸手指着他、张嘴争辩，姿态凌乱拥挤，像在围攻。
> 包围式构图。

关键：用「围住 / 一圈 / 包围式构图」这类词，光写「站在旁边」会变成排队。

### 2.5 场面/动作（逃命、拍案、点火）

> 一个年轻的中国古代君主猛地从案后站起来，一掌重重拍在案几上，
> 案上的竹简被震得飞起来，他怒目圆睁、下巴抬起，气势十足；
> 他左右两边各有一个文官吓得缩起肩膀、往后躲。横向构图，君主在画面偏左。

关键：**动作要有「结果」**。「拍桌子」不够，要「竹简被震得飞起来」。
一个可见的后果，比十个形容词有效。

### 2.6 信息图插图（小、要能看清剪影）

> 横向并排三个完全独立的小场景，彼此之间留出大片空白、绝不重叠、
> 没有任何边框和分隔线。左边场景：三个古代文官挤在一起互相推搡争吵，手臂乱举；
> 中间场景：一个戴纶巾的文士伸手指着对面一个文官的鼻子，那个文官身体后仰、双手举起；
> 右边场景：三个文官同时瘫坐在地、垂头丧气、袖子堆在地上。
> 三个场景要小，每个场景只占画面宽度三分之一。

关键：出图后要按列切三块（见 `scripts/comic_layers.py` 的 `fit="contain"`）。
所以**场景之间必须有大片空白**，不写这句必定粘连。

## 3. 反向约束词表（哪个出问题加哪个）

| 现象 | 加到尾部的话 |
|---|---|
| 出现乱码汉字 | 绝对不要画任何文字、字母、符号、数字 |
| 出现对话框 | 绝对不要画气泡、对话框、边框、分格线 |
| 有灰阶/阴影 | 绝对不要灰度、不要阴影、不要渐变、不要排线、不要网点 |
| 有纸纹/做旧 | 纯白背景，不要纸张纹理、不要噪点、不要做旧效果 |
| 有颜色 | 只有黑色和白色，不要任何彩色 |
| 照抄参考图姿势 | 不要画举起手臂的动作，不要画手指比 V 字 |
| 人物被裁 | 全身或半身完整落在画面内，不要裁切 |
| 人物太小 | 人物占画面高度的 80% 以上 |
| 顶部没留白 | 画面上方留出大片纯空白（约占画面高度 25%） |
| 画了真人照片风 | 简笔漫画，不是写实插画，不是照片 |

## 4. 失败模式对照表

| 出来的样子 | 原因 | 修法 |
|---|---|---|
| 手举起来比 V | 参考图相似度太高 | 相似度调 low + 加「不要举手」负向词 |
| 三个人排排站，没有互动 | 只写了「站在一起」 | 改「都伸手指向右侧那个人」 |
| 人物糊成一团 | 一次写了 5 个人 | 减到 3 人，或拆成两格 |
| 线条发灰、有阴影 | 前缀被截断或漏写 | 风格前缀必须逐字全带 |
| 出现假中文 | 漏了「不要任何文字」 | 补上；台词永远由代码叠 |
| 人物贴在画面顶上 | 漏了「上方留白」 | 补上；或出图后脚本会裁白边 |
| 四个人长得一样 | 没区分身份 | 给每人不同冠帽/胡子/胖瘦 |
| **主角和配角像同一个人** | 主角戴了和配角「同款只是矮一点」的冠 | 主角换**异类**头饰（软布巾 / 无冠），并去掉胡子；见 §2.0 |
| 只有脸没有身体 | 写了「特写」 | 要身体就写「半身像」 |

## 5. 参数对照（不同工具）

| 工具 | 参考图参数 | 建议值 |
|---|---|---|
| ImageGen | `input_fidelity` | `low` |
| Midjourney | `--iw` | `0.3 – 0.5` |
| Stable Diffusion | IP-Adapter weight | `0.35 – 0.5` |
| 即梦 / 可图 | 参考图强度 | 低（30% 左右） |
| 通用 | image_weight | 够继承画风即可，**不要追求高相似** |

尺寸建议 `1:1` 或 `3:4`。脚本会把图裁进 1080×1200 画布，横图会让两侧留白过多。

## 6. 一次出图，出几张？

**一格一张。** 不要试图一张图讲完三个回合 —— 那些是三个格子。

单格生成成本很低，重出单格也不心疼。反过来，一张图塞太多信息，
不是画糊，就是人物连成一片、大块抢时间（引擎按 √面积分时长）。两个坑一起来。

### 人物连成一片：prompt 侧能做的三件事

`largest_share` 长期 80% 以上的图，进引擎后是「一大块一口气描完」，
前两三秒铺满、后面全程静止。这个指标**可以在 prompt 里降下来**，
比事后切图有效得多（切图已证实无效，见 `comic-story.md` §4.4）。

实测《惠州》羊肉摊那格，改三处、一次到位：

| 改法 | 作用 |
|---|---|
| 「皮围裙」→「**浅色布围裙**」 | 最大的一处黑块没了 |
| 加「不要大片涂黑、不要灰色填满整件衣服」 | 防止官袍、围裙、盔甲被涂成实心 |
| 加「彼此之间留出空隙、不要贴在一起」 | 两个人不再连成同一个连通域 |

三条一起加，成本为零。t95 从 52% 回到 61%，`largest_share` 从 96% 降下来。

> 但要注意：**别把衣服全改成纯白**。两个人全白会互相「融进背景」，
> 人物轮廓就散了。正确做法是「白底 + 浅灰线条衣褶」，或者一人浅衣、
> 一人短打，靠**深浅差异**把人分开。


#### 连通域连成一片的第二个成因：**手和道具互相接触**

上面三条治的是「深色衣物被涂成黑块」。但还有一种情况：**画风完全正常、
没有黑块、颜色也干净，画面看着毫无异常** —— 文士伸手去接竹篮，
老汉也伸手去接竹篮，鹿站在中间，三个主体靠这几只手连成了一个连通域。

肉眼看不出问题，只有量才知道。看到这种「手指碰到道具、两个人手交手」的构图，
直接改掉，别等出片才发现：

| 改法 | 作用 |
|---|---|
| 「伸手指着」→「**双手拢在袖中**」「背在身后」 | 手不碰道具，主体断开 |
| 「伸手接篮子」→「**站在一旁看着**」 | 同上 |
| 加「**任何两个主体之间都不能碰触、不能连在一起**」 | 强制留白 |
| 两条船 → 加「**中间隔着一大片空海面，两条船绝对不相碰**」 | 船板断开 |
| 人物和案桌 → 「人**站在桌前半步远**，不要扶桌沿」 | 桌椅不再连人 |

**怎么量**（一条命令，不用写代码）：

```bash
python scripts/pipeline.py <项目目录> --stage image
```

它会打出每格的 `墨%` / `最大块` / `中灰`，并把「缺图 / 几乎空白 / 整片涂黑」
判为 ✗。

> **但「最大块 >90% 就重出」这条规则已经废除了。** 量了 6 个已出片成功的项目，
> 91~96% 的五格里有三格节奏完全正常（惠州 s7 95.0% → t95 57%、惠州 s4 91.1% → 57%、
> 佛印 s8 92.4% → 67%）。**单人图的人物轮廓天然就是一块**，这个数天然很高，
> 拿它当门禁会把好图判死，白花 credits。
>
> 真正能判「画得快不快」的只有渲染后的 `ink_probe` 曲线：
>
> ```bash
> python scripts/ink_probe.py <项目目录> --part s3
> ```
>
> 所以顺序是：出图（不改构图）→ 渲一格 → 量 t95。t95 明显低于 55% 才回头改 prompt。
> 反过来，只在看到「手交手 / 手扶道具 / 两个主体贴在一起」的构图时提前改 ——
> 那个是可以直接看出来的，不用等渲染。

#### 气泡坐标：默认不用填

**`cx/cy/rx/ry` 都可以不写**，`comic_layers.py` 会按字数自动排版。
只写 `{"text": "你吹的牛呢？"}` 就能出片。想让气泡指着某个人，只加一个
`tail: [x, y]` —— 气泡自己会跟过去。

不想手填是因为：填准坐标得看 `boards/` 量头顶、叠预览、再挪，一格三五轮，
每次看图 1.5–2.5k token。**而差 30–50px 在成片里看不出来。**

真要做（比如同一格两人对吵、气泡非得分左右），用连通域算头顶比目视准：

```python
from scipy import ndimage
lab, n = ndimage.label(ink, structure=np.ones((3, 3)))
sub = lab[y0:y1, x0:x1]                       # 只在这个矩形里找
ids, counts = np.unique(sub[sub > 0], return_counts=True)
best = ids[counts.argmax()]
ys, xs = np.where(lab == best)                # ys.min() 就是这个人头顶
print(f"头顶 y={ys.min()}  水平中心 x={(xs.min()+xs.max())//2}")
```

#### 信息图格：两行字不能叠在同一坐标

同一格里画两行字，如果第二行的 y 坐标跟第一行重复，两行会**重叠成一团糊字**。
上一版 s2「官运年表」就是这么废的：红字「人没到任」直接压在灰字
「授翰林院检讨」上面，完全读不出来。

**每行字要占自己独占的 y。** 而且红字回击**不能挂右端** ——
右下角有自动贴的底衬插图（`655,715,365,425`），字尾巴会被那张图压住。
实测把红字从 9 字缩到 4 字、箭头终点从 x=520 收到 x=404，才避开底衬。

#### 信息图不能剧透，也不能复述

信息图的职责是「给一层新意思」，不是做目录。

实测《陈白沙》s5 初稿把三件怪事全列在图上 —— 既剧透了第 6 格才揭晓的
第三件，又复述了第 3、4 格刚讲过的内容。改成只列前两件 + 第三行留「？」，
底行给一句共性「动心的都不是他／都是别人自己找上门的」，才立得住。

判据：**读图的人不应该比听声音的人先知道结局。**

批量时建议：**同一次会话里连续出，风格漂移最小**。
跨会话出图，最好重新把锚点图再传一次。

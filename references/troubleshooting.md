# 出错了查这里

按症状查。处置列只给动作，不给解释。

## 画面

| 症状 | 真因 | 处置 |
|---|---|---|
| 一格两秒就画满，后面不动 | 传了 `regions` / `element_plan`，物体按 1.6s 上限画完即停 | 删掉 `regions`，重跑渲染（几十秒，零成本） |
| 一格九成时长还在画 | `DRAW_BUDGET` 太高 | 降到 0.7–0.75 |
| 换了图但成片画面没变 | 分拍缓存只比时长 | 已修：`render_explainer.py` 写 `.stamp` 指纹，变了自动重渲 |
| 合并报「分拍合计 ≠ 成片时长」 | 分拍 mp4 是按旧音频渲的 | 已修：比对缓存时长，差 >0.15s 自动重渲 |
| 背景是荧光绿 | `blend=all_mode=multiply` 在 YUV 空间算 | 改 `colorkey` + `overlay` |
| 信息图一直轻微晃、字边毛刺 | `zoompan` 缓推的裁剪窗取整抖动 | 删 zoompan，改静止 + 0.35s 淡入 |
| 线稿画出来是墨团 | 灰阶边缘被骨架化当笔画 | 进引擎前必须二值化去噪（`comic_boards.py` 自动做） |
| 气泡压着脸 | 出图没留顶部空白 | prompt 加「上方留大片纯空白」 |
| 人物太小，尾巴拖很长 | 原图四周空白太多 | 脚本自动裁白边并放大，不用管 |
| 空镜像卡住 | 信息图是静帧 | `pad` 加 1–3 秒；不要加 zoompan |
| 时长对不上 | concat 混入坏分片 | 删 `out/segs` 重跑 |
| 渲染 `ArrayMemoryError` | 1080 画布需 ≥3GB 可用内存 | 关掉别的程序，或临时降到 900 宽 |

## 节奏诊断

怀疑某格画得快时，**不要看曲线数字**，先查两件事：

```bash
# 1. plan.json 里有没有手写的 regions —— 这是唯一确定的真因
grep -c '"start"' <项目>/plan.json

# 2. 没有 regions 就看成片：抽两帧对比
ffmpeg -y -ss 3 -i <项目>/out/final.mp4 -vframes 1 <项目>/check/a.png
```

有 `regions` → 删掉重渲染。没有 → 图正常，往下走。

以下数字**没有判定线**，只记录、不作结论：最大块占比、中灰占比、连通域个数、面积 t95、活跃占比。
已出片的片子在这些指标上横跨整个区间，拿来当判定线只会白重出好图。

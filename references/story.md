# 怎么把选题变成一个故事

写念白之前读这份。顺序不能颠倒：**先有问题，再有格子，最后才是句子。**

> 这份文档讲判断，`references/example.md` 讲成品。两样一起看：先看那版八格念白长什么样，再回来对方法。

---

## 一、把选题压成一个问题

选题是一句话（一个朝代、一家公司、一个人、一样东西）。它不是故事。

**第一步：找出这个选题里「说不通」的那一点。** 故事的驱动力是疑问，不是信息。

把想到的问题和它的答案一起写下来，然后判断：

- 答案是一串时间线 → 废掉，重挑。观众不需要你的片子，查资料更快。
- 答案是「哦，原来是这样」 → 成了。

| 废掉的问题 | 成立的问题 |
|---|---|
| 某人是怎么发展起来的 | 一个卖纸牌的，凭什么做游戏机？ |
| 某人在某地做了什么 | 一个被贬到天涯的人，凭什么睡得比在京城还香？ |
| 某人怎么应对强敌 | 一个人，一米四，怎么让一整国闭嘴？ |
| 一家大公司为什么衰落 | 全世界都看见智能手机了，为什么只有它没看见？ |

**第二步：把答案想清楚。** 想不到「哦，原来是这样」那句话，说明还没找到问题。

答案不许是「因为他努力」「因为时代变了」。那等于没有答案。

```
story_line  谁 / 想干什么 / 卡在哪 / 结果      一句话说完
question    开场砸出来的那个问题
answer      最后一格给出的答案
```

## 二、按「主角和阻力」选骨架

同一个「提问 → 一层层挖 → 回答」，在不同题材里有四种走法。先认形态，再排格子。

### 交锋型 —— 阻力是一个具体的对手

```
对方摆阵 → 出招 → 化解 → 加码 → 化解 → 最狠一招 → 化解 → 收
```

- 对手的招必须**一次比一次狠**。三回合同一个动作，第二遍观众就疲了。
- 递进可以换维度（嘴 → 纸 → 心）、换代价（挨骂 → 挨整 → 挨贬）、换信息（不知道 → 猜到 → 确认）。
- 不是每场都有反杀。主角一路输也行，别硬造「零比三」这种假比分——那样每格都在报分。

### 转型型 —— 阻力是自己那条路走不通了

```
老本行快死了 → 试了几样都不成 → 意外冒出一件 → 押上去 → 成了 → 才明白自己卖的到底是什么
```

- **张力在主角心里：他不知道该卖什么。** 没有对手。
- 一旦给它配上回合，等于硬塞一个对手，故事立刻变成年报。
- **低谷必须占格子。** 试错全赔那段要单独成格，不能一句话带过；后面全是报喜，观众不会揪心。

### 探案型 —— 阻力是一个说不通的现象

```
反常的事 → 找到那个人 → 他当时的难处 → 他怎么解的 → 结果
```

- 答案不许提前说。说早了，后面全是解释。
- 查到的东西要一层比一层意外，否则不叫查。

### 代价型 —— 阻力是一个没人当回事的裂缝

```
巅峰 → 一道裂缝 → 谁都没当真 → 押错 → 塌 → 收场
```

- 观众要比主角先看见裂缝，才有揪心的余地。
- 别写成成功学。裂缝必须真的被忽略过。

## 三、每格的任务

```
格1    把问题砸出来     具体场景，不是背景介绍。观众心里悬起一个疑问
格2    让人看见有多难   赌注。一句话讲清输了会怎样（信息图格放这里，全片最多 2 格）
格3-6  一层层往下挖     每格结束，观众心里多一个新问题
格7    最后一块拼上     事实层面完成，最后一个转折
格8    答掉开场的问题   bg 改 cream，安静下来
```

格数跟着故事走。5 格讲完就 5 格，9 格才讲完就 9 格。
**不要为凑格数把一个动作拆成两格**——那是「回合」的来源。

每格三种画法：

- **对话格**（`bg: sky`）：2–5 人，彼此有动作关系（指着、躲开、围住、瘫坐），橙色气泡 ≤8 字
- **信息图格**（`bg: cream`）：3 行主体，一行一个大信息，全片最多 2 格
- 信息图**不许剧透**：读图的人不该比听声音的人先知道结局

## 四、结尾

只讲完事件就结束，观众的反应是「啊？没了？」。最后一个转折是钩子，不是落点。

**落点 = 开场那个问题的答案。** 答不上来，是故事没讲完，不是缺一句金句。

- `bg` 改 `cream`，语气降下来，不要再加包袱。
- 气泡最多一个，两个字最好（「值了」）。它是句号，不是又一段对话。
- 答完还有余力，才加一句短的。**兜里没有好句子就别硬憋**——硬憋出来的是格言串烧，观众记住的是句式，不是人。

## 五、句子怎么写

### 三条底层

**降格。** 宏大叙事换算成日常场景。换算不了，说明还没想明白。

| 原事 | 降格后 |
|---|---|
| 舌战群儒 | 一个人怼一屋子 |
| 三顾茅庐 | 老板连着三次上门求人，被晾在门口 |
| 合纵连横 | 六个老板组群聊，各自偷偷私聊对手 |

**拆穿。** 把漂亮话翻译成大白话，而且翻得更毒。公式：抽掉「体面」，只留「诉求」。

> 「你自比管仲乐毅，怎么跟了刘备越跟越惨？」→「**你吹的牛呢？**」

**自曝。** 主角必须有缺点。完人不好笑，也不好亲近。给主角一个小毛病，读者才会站到他这边。

### 六个手法

| 手法 | 怎么写 | 例 |
|---|---|---|
| 垫话开场 | 先跟观众搭一句，再进正题 | 「今儿说一位——」 |
| 自问自答 | 问一句自己接，制造有人搭腔的错觉 | 「好肉呢？轮不着他。」 |
| 重复三遍 | 同一个词连说，第三遍加码 | 「往南，往南，再往南——没路了。」 |
| 破折号蓄势 | 包袱前用 `——` 停半拍 | 「第二天——三百颗。」 |
| 数字砸下来 | 抽象的量换成具体的数 | 「二十间房」「五十九岁」 |
| 口语连接词 | 搁那年头 / 您算算 / 更绝的在后头 | 替换「因此」「由此可见」 |

开场不要老用同一句式。连续几条片子都「各位，今儿说……」，就成了模板腔。

### 要删的东西

- 书面连接词：因此、由于、综上所述、由此可见
- 概括形容词：十分豁达、颇为感慨
- 自我说明：总结一下、值得一提的是
- 占位符：他回了一句、批了俩字、一句话把他点醒

### 字数

按 **4.0 字/秒** 反算，标点算字。`目标秒数 × 4.0 = 字数上限`。
110–135 秒 → 440–540 字。按 4.7 算会超时 18%，然后你会想压 `speed` 救它——那正是毁节奏的做法。

## 六、写完自检

1. **盲听一遍，能说出这条片子想问什么吗？** 说不出 → 没有故事，回第一节重挑问题。
2. **最后一格把那个问题答掉了吗？** 没有 → 结尾在拖，或者问题挑得太大。
3. **有没有哪一格只有结论、没有具体动作？** 有 → 补一个能听见的落脚点：具体物 + 动作 + 结果。
4. **念出来绊不绊嘴？** 绊 → 断句或换词。

一条片子 440–540 字，说完事、说完话、说完落点，字数刚好。砍字数砍的是废话，不是台词。
砍完发现每格只剩「他说了一句」，说明砍错了地方。

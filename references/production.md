# 制作参数

写 prompt、定角色、排气泡、配音、渲染、合成——所有"填什么值"都在这里。

---

## 一、两类格子的版面

### 对话格（`bg: sky`）

| 层 | 元素 | 要求 |
|---|---|---|
| 1 | 2–5 个角色 | 彼此有动作关系：指着对方、躲开、瘫坐、围住。不是并排站肖像 |
| 2 | 台词气泡 | 橙色椭圆，尾巴指向说话的人，一句一个，≤8 字 |
| 3 | 强调圈 | 红色手绘圈，全格只压一处（一般是不说话那个人的眼睛） |
| 4 | 底色 | 浅蓝 `#CBE3F5`，底部不加字——留给大字幕 |

「三个人站成一排」是肖像，「三个人伸手同指右侧」才是分镜。

### 信息图格（`bg: cream`）

| 层 | 元素 | 要求 |
|---|---|---|
| 1 | 标题 + 副题 | 标题 64 号，副题 30–34 号（红或灰） |
| 2 | 3 行主体 | 每行一个大信息，层级最多两级 |
| 3 | 序号标签 | 黄色圆角块 + ①②③ |
| 4 | 箭头 + 回击 | 红箭头 + 红字，一行一句话 |
| 5 | 分隔线 | 极浅的 2px 横线，不要实框 |
| 6 | 底色 | 米黄 `#FAF2E0` |

字号下限 26，右侧留 60px。**每行字占自己独占的 y**，两行同一 y 会叠成糊字。
红字回击不要挂右端——右下角有自动铺的底衬图（`655,715,365,425`），字尾会被压住。

信息图右下角**自动铺一张淡掉的底衬**（脚本按「上一格优先」挑图，按墨迹裁切，`opacity=0.28`）。
不用写代码，也不要自己 `art()`。某格不想要时写 `"backdrop": false`。

## 二、出图

### prompt 三段结构

```
[风格前缀]  +  内容：<谁> + <什么表情> + <什么动作，朝哪> + <在哪>  +  [尾部约束]
```

风格前缀逐字照抄 `scripts/comic_gen.py` 的 `STYLE`，一个字不改。它是**排除清单**，不是描述——
模型默认会加阴影、加灰阶、加纸纹，每一样都会让引擎把噪点当笔画描。

尾部两句也一个字别省：

> 画面上方留出大片纯空白（留给对话气泡）。
> 绝对不要画任何文字、气泡、标题、对话框、边框、水印。

### 角色身份证

写 prompt 之前先给每个角色定四个字段，**任意两人至少三项不同**：

| 字段 | 说明 |
|---|---|
| 头饰 | 最容易撞。主角用异类（软布巾 / 无冠 / 儒巾），方冠、冕冠、头盔留给对手和兵 |
| 胡须 | 有 / 无 / 长短 |
| 衣服 | 颜色 + 款式，浅色为主 |
| 体型 | 写成**可比较的参照**：「头顶只到旁边那人胸口」，不要写「矮个子」 |

两条硬规则：

1. 主角的头饰要跟所有配角**不同类**。戴一顶「矮一点的同款方冠」是无效区分，模型只会画同款。
2. 主角跨格固定同一组合，每格都写一遍完整四字段，别写「还是那个人」。

prompt 末尾复述一次对比：「帽子样式和胡须绝对不能一样」。

### 服装不能是深色

「皮围裙」「黑袍」「盔甲」「深灰色僧袍」会被涂成一坨纯黑，二值化后衣褶全丢。
写**浅色布衣** + 「不要大片涂黑、不要灰色填满整件衣服」「人物之间留出空隙、不要贴在一起」。

别反过来全改纯白：两个人全白会融进背景，轮廓散掉。用深浅差异把人分开。

### 构图：手不要碰道具

「伸手接篮子」「扶桌沿」「两个人手交手」会让主体连成一个连通域，笔画顺序全乱。
改成「双手拢在袖中」「背在身后」「站在桌前半步远」，再加一句「任何两个主体之间都不能碰触」。

这类问题**看图就能看出来**。看到就改 prompt（零成本），不要等渲染完去量数字。

### 多角色格的写法

- 每个人都要写「在画面哪一侧」，不写会挤成一团。
- 同一个动作重复两遍（「都伸出右手臂，手臂水平指向右侧」+「手臂都指向同一个人」）。
- 人数 ≥3 时必须说清「谁指谁」，否则会互相指。
- 一次超过 4 人容易糊，减人或拆格。

### 出图参数

| 工具 | 参数 | 值 |
|---|---|---|
| ImageGen | `input_fidelity` | `low` |
| Midjourney | `--iw` | 0.3–0.5 |
| Stable Diffusion | IP-Adapter weight | 0.35–0.5 |
| 即梦 / 可图 | 参考图强度 | 约 30% |

尺寸 `1:1` 或 `3:4`。横图会让两侧留白过多。

### 批量出图的文件映射

**按时间戳取，不要按 `sorted()` 的位置。** 同一次会话出多张时，工具按 prompt 前几个字命名；
只要有一张开头不同，顺序就全乱，而且净化、气泡、渲染会一路照错的那张走下去，不报错。

```python
stamp = {f.name[-23:-4]: f for f in Path('_gen').glob('*.png')}
g6 = stamp['2026-11-03T07-18-08']      # 文件名末尾的时间戳
```

映射完跑 `contact_sheet.py` 看一眼名字对不对，不用每张单独开。

## 三、气泡

### 默认什么都不用填

```json
{"text": "你吹的牛呢？"}
```

- `at` 不写 → 按念白字符级对齐反推（写在念白哪一句，就在那时弹）
- `cx/cy/rx/ry` 不写 → 按字数排版，居中放上部，多颗依次往下

想让气泡指着某个人，只加 `tail: [x, y]`，气泡自己跟过去（出画会自动翻到下面）。

### 什么时候才手填

- 同一格两颗气泡必须左右分开（两个人对吵），自动排会排成竖列
- 气泡会盖住关键画面，要挪到另一侧
- 信息图格上要按版面精确放

手填只填 `cx/cy`，`rx/ry` 让它自动算。代码规则是「四个都填才用手填，缺一个就全自动」。

### 写了 `tail` 就要确认左右

出图不保证按你写的方位摆人。prompt 写「甲在左、乙在右」，出图可能反过来；
照 prompt 方位填 `tail`，台词就指到了错的人头上——这是叙事错误，观众会以为话是另一个人说的。

顺序：看图记下**实际**左右 → 每句台词对一遍是谁说的 → 决定 `tail` 的 x 落在哪侧。
**不写 `tail` 就没有这个问题**，气泡不指人，放在上部中间。

### 气泡进不去引擎

引擎会把彩色二值化成黑块，所以气泡在合成时叠，按时间弹。

## 四、配音

单口，一个人说书，不要捧哏、不要第二个音色。

```json
"tts": {"engine": "apiz", "model": "speech-2.8-hd", "voice": "xiangsheng01", "speed": 1.0}
```

音色不从公共池里挑（`tags` 字段全是坏的），用自然语言描述生成一个：见 `voice-design.md`。

- **`speed` 固定 1.0。** 节奏靠文本给（垫话、重复、破折号），靠 atempo 压时间会把气口压没。
- 换引擎或音色会自动整批重配——`.sig` 指纹里带了这两个字段。
- 临时音色 168 小时不用会被回收，描述要留在项目里。

edge 只在 apiz 不通时当兜底：`"engine": "edge"`。播音腔，别指望语气。

## 五、渲染：绘制节奏

引擎有两条调度路径：

| 传了什么 | 行为 |
|---|---|
| 传 `element_plan` / scene 带 `start`+`end` 的 `regions` | 每个物体按自然时长画，**上限 1.6 秒，画完即停** → 整格两秒画满 |
| 什么都不传（默认） | 按 √面积 把 `draw_duration` 分给每个连通域，总时长恒等于预算 |

**所以不要传 `regions`。** 想要画面对就调 `draw_duration`，不要去切带、下刀、切 box——那些都试过，无效。

## 六、合成

### 底色

```bash
# ✓ 正确
colorkey=0xFFFFFF:0.12:0.04  +  overlay

# ✗ 错误：multiply 内部按 YUV 算，浅蓝 (202,226,244) 会变成荧光绿 (89,255,84)
blend=all_mode=multiply
```

写了 `format=rgb24` 也没用，色度分量照样被乘掉。

### 字幕

```bash
# ✓ 自己写 ASS，声明坐标系
subtitles=subs.ass

# ✗ SRT + force_style：libass 落到 384×288 默认坐标系，58 号字变成几百像素飞出画面
subtitles=subs.srt:force_style='FontSize=58'
```

ASS 头必须写 `PlayResX: 1080` / `PlayResY: 1920`。
时序按「分镜时长 + 字数比例」分配，尾部留 4% 静音，别顶到最后一个字。

### 信息图不要加 zoompan

输入 = 输出分辨率时，裁剪窗宽 `1080/zoom` 是小数，ffmpeg 每帧取整 → 每两三帧横竖各跳 1px，
字边一直在「呼吸」。用**静止 + 0.35s 淡入**：

```bash
-fade=t=in:st=0:d=0.35,format=yuv420p
```

想让信息图有节奏，改成拆层逐行淡入（①②③ 依次出现），代价是 `charts.py` 要按步骤输出多张 png。

### 竖屏

```
平屏 1080×1200  →  pad 到 1080×1920，顶部偏移 324
                →  烧 subs.ass
                →  loudnorm=I=-16:TP=-1.5:LRA=11
```

顶部留白给标题，底部留白给字幕。别把画面顶到最上面。

## 七、改完之后重跑哪几步

| 改了什么 | 必须重跑 |
|---|---|
| 念白一句话 | `comic_tts.py` → `comic_run.py`（跳过 layers/boards） |
| 气泡文案 / 位置 | `comic_layers.py --only bubbles` → `comic_finish.py` |
| 换了一张出图 | `comic_boards.py` → `comic_layers.py` → `comic_run.py` |
| 信息图排版 | `comic_layers.py --only charts` → `comic_finish.py` |

改念白一定要重配音：时长变了，分拍不重渲就会出现画面比声音长。

# 一版合格的念白

> 下面这条用的是公共史料，跟任何项目无关。**看形状，别看内容。**
> 八格，466 字，约 116 秒。

## 全文

| 格 | 念白 | 气泡 |
|---|---|---|
| 1 | 1928年9月，伦敦。弗莱明度完假回来，桌上堆着一摞没洗的碟子。他抽出一碟——里面长了霉，霉的周围，一圈细菌化没了。他拍了照，写了两页，把碟子搁在一边。这一搁，十二年。 | |
| 2 | 搁下的理由很实在：他要把那点霉汤拿来治病，可一提就坏，一放就浑。一个人，没设备，也没钱。他手上还有更要紧的活——那阵子他在找流感病毒。 | 「提不出来。」 |
| 3 | 这十二年，几乎什么也没发生。那株霉装在玻璃管里，塞在抽屉。没人来要，他也没再提。1939年，欧洲开打。 | |
| 4 | 牛津一间旧楼里，两个人翻旧文献，翻到那两页。一个懂菌，一个懂化学。他们写信到伦敦，弗莱明把抽屉里那管霉寄了过去。 | 「寄一管给我。」 |
| 5 | 难在哪？几百碟霉汤，才够一个病人用一天。他们拿牛奶罐当发酵罐，拿浴缸当冷却槽，把实验室改成了车间。 | |
| 6 | 1940年，几只打了致命菌的老鼠活了下来。第一次有人证明：那碟霉，真能打进身体里治病。 | |
| 7 | 1941年2月，一位警察脸上感染，烧得说胡话。药推进去，第二天退烧，第五天他能坐起来。药没了。他们把病人的尿收回来，再抽一遍。他还是死了。 | 「药不够了。」 |
| 8 | 所以不是一个人救了上亿人。是他看见了，然后有人肯花十二年，把那碟霉汤，做成能打进人身体的东西。 | |

## 它为什么成立

**一、格与格换不了位置。**
把第 4 格（牛津来信）挪到第 3 格前面，观众就不知道为什么这十二年没人动它。
把第 7 格（第一个病人）挪到第 6 格前面，那只老鼠就白死了。
**八格里每一格都咬住上一格的结果**，这是故事和清单的分界线。

**二、每一格都有人在动手。**
抽出一碟、拍了两页、塞进抽屉、写信、寄过去、拿牛奶罐当发酵罐、把尿收回来再抽一遍。
没有一格是「关于弗莱明的介绍」，全是他在做一件具体的事。

**三、全篇没有解说员。**
没有「我们先看看背景」「看出规律没」「这里有个规律」「再说个细节」。
叙述的人一直在画面外面，只报看见的东西。

**四、最狠的一格不是金句，是事实。**
第 7 格结尾是「他还是死了」。第 8 格结尾是「做成能打进人身体的东西」。
两句都是具体的东西，没有一句对偶，没有一句能单独摘出来当标题。
**观众记住的是那个警察，不是句式。**

**五、结尾答的是第 1 格提出的问题。**
第 1 格留下「这一搁，十二年」，观众心里挂着一个「为什么」。
第 8 格答：因为从看见到能用，中间隔着十二年没人干的工程活。
问和答在同一个点上闭合，所以听完是「哦，原来是这样」，不是「啊？没了？」。

## 套到别的题材，改什么

形状不变，只换三样：

| 要素 | 这条里是 | 换题材时怎么找 |
|---|---|---|
| 一个具体的动作开场 | 度假回来抽出一碟 | 找一个「手上正在做的小事」，不要写年代和身份 |
| 一个说不通的空白 | 十二年没人动它 | 时间断层、金额对不上、所有人都绕开的那一步 |
| 一次失败 | 第一个病人药不够死了 | 最接近成功却失败的那一次，比成功更能立住人 |

## 写完自己的八格，问三句话

1. **把这一格删掉，后面还成立吗？** 成立，这格是填充，删掉或者并进邻格。
2. **和前后对调，故事还通吗？** 通，说明它不是情节，是排比。
3. **这一格里有人动手吗？** 没有，你在讲信息，不是在讲故事。

三句里有一句答不上来，就回去改那几格，不用管字数。
